# ARENA ONLINE

2人オンライン対戦ゲーム

## 起動

Renderで以下を設定：

Build Command
npm install

Start Command
npm start

## ゲーム仕様

- ストック3
- ダメージ％制
- ダメージが高いほど吹っ飛びやすい
- 場外で撃墜
- ストックがあればリスポーン
- リスポーン直後は無敵
- 通常攻撃
- 必殺技3種
- 連続ヒット抑制
- 2人オンライン対戦
- ルーム作成・参加
- キャラクター選択
- ステージ選択
- PC操作
- タブレット操作
