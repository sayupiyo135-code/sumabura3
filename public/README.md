# ARENA ONLINE

2人オンライン対戦ゲーム。

## Render設定

Build Command:

npm install

Start Command:

npm start

## ゲーム仕様

- ストック3
- ダメージ％制
- ダメージが高いほど吹っ飛びやすい
- 場外に落ちると撃墜
- ストックが残っていればリスポーン
- リスポーン直後は無敵
- 通常攻撃
- 必殺技3種
- 同じ攻撃の連続ヒットを抑制
- 2人オンライン対戦
- ルーム作成
- ルーム参加
- キャラクター選択
- ステージ選択
- PC操作
- タブレット操作
